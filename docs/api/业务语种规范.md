# 业务语种规范



## **设计原则**



**BCP 47 是格式基础，本表是三方合约。**



BCP 47 language tag 定义了语种代码的书写格式：小写语言代码，可选地区子标签，以 `-` 分隔，例如 `en`、`zh-TW`、`fil`。本文的代码格式遵循 BCP 47。



本表（22 个代码）是 CPP / AI / RS 三方共同使用的语种合约。**三方在各自字段中直接使用本表的字符串，不需要在服务之间维护映射表，也不需要运行时转换。**



BCP 47 支持语言代码不带地区子标签，例如 `pt` 表示"葡萄牙语，不区分地区变体"，语义明确，不是歧义。`pt-BR`、`pt-PT` 是更具体的子标签，是 `pt` 的下级。业务不需要区分地区时，直接用语言代码（如 `pt`、`es`）即可；未来需要区分时，在本表新增具体子标签（如 `pt-BR`），与 `zh`/`zh-TW` 的处理方式相同。



其中一个代码与 BCP 47 标准不同：



|代码|BCP 47 标准值|原因|
|---|---|---|
|`in`|`id`（印尼语）|CPP 历史沿用值（源自 Java Locale 旧写法），三方统一用 `in`，不使用 `id`|



`fil`（菲律宾语）是合法的 BCP 47 tag（IANA 注册），优于 `tl`（仅指 Tagalog），不是偏差值，无需映射。



三方统一用本表代码。**\*\*任何服务都不应将 \`in\` 映射成 \`id\` 后再传给其他服务。\*\*** 只有对接使用标准 BCP 47 的外部系统时，才在对接层做 \`in\` → \`id\` 的单向映射。

## **各服务使用方式**



各服务直接使用本表代码，按下表处理。



|服务|字段|行为|
|---|---|---|
|CPP|`subtitle_language`、`assets[].language`|传入本表代码字符串，例如 `"in"`|
|AI 打标服务|接收 CPP 的 `subtitle_language`|按本表校验；不识别返回 `invalid_request`|
|AI 翻译服务|请求体的 `target_language`|按本表校验；不识别返回 `unsupported_language`|
|RS|翻译版 schema 的存储键|以本表代码归档；基础版键为 `zh`|



三方代码一致，无跨服务映射。



## **AI 服务语种获取接口**



获取 AI 服务当前可用的基础语种列表。该接口不接收 `job_type`，不返回 `poster_title_image` 业务参数。



本节给出调用方需要读取的最小字段；共享语种目录的当前服务合同以 [`service-contract.md`](service-contract.md) 为准。`poster_title_image` 可提交语种以任务创建接口的约束和服务端校验为准。



服务端语种字典由 `app/core/language_catalog.py` 统一维护。当前 `languages[].language` 返回本文业务语种列表；新增地区变体或新语种时，先按本文扩充规则进入业务语种列表，再同步语种字典、接口测试和调用方。



`language` 是唯一程序化键；`display_name` 和 `native_name` 只用于展示，调用方不应基于展示名称做逻辑判断。



### Method / Path



```http
GET /api/v1/ai-jobs/languages
```



### Response Example



```json
{
  "code": "0",
  "msg": "success",
  "data": {
    "languages": [
      {
        "language": "es",
        "display_name": "Spanish",
        "native_name": "Español"
      },
      {
        "language": "pt",
        "display_name": "Portuguese",
        "native_name": "Português"
      }
    ]
  },
  "request_id": "01J...",
  "server_time": "2026-06-24T12:00:00+00:00"
}
```



| 字段 | 类型 | 说明 |
|---|---|---|
| `data.languages` | array | 当前接口返回的可用语种列表 |
| `languages[].language` | string | 提交任务时使用的语种代码 |
| `languages[].display_name` | string | 英文展示名称 |
| `languages[].native_name` | string | 本地语言展示名称 |



## **外部系统对接**



若需与使用标准 BCP 47 的外部系统（如第三方翻译 API、语言检测服务）对接，应在**对接层**做单向映射：



```Plain Text
in → id
```



此映射属于各服务的内部实现，不在本文维护，也不影响三方之间的代码传递。



## **扩充规则**



新增语种时先更新本表，再同步各服务实现，不在各自文档维护独立副本。
