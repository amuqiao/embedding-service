## 2. 后端对接职责

### 2.1 后端负责的功能

✅ **业务后端必须实现**：

- 用户和项目管理
- 原文长期存储
- 用户 PromptConfig 编辑和保存
- AI Job 生命周期追踪（create → poll → complete）
- 步骤状态机（step1 → step2 → step3）
- 上一步结果存储（用于后续步骤输入）
- 用户决策（是否接受校验建议，是否重跑）
- Callback 签名验证和幂等去重
- 任务失败告警和人工介入

### 2.2 对接验收标准

**初始化阶段**：
- [ ] 能正确调用 `/health`
- [ ] 能正确调用 `/models` 和 `/prompt-templates`
- [ ] 环境变量和密钥配置完成

**功能对接**：
- [ ] 能成功创建 step1 Job（返回 202）
- [ ] 能正确轮询 Job 状态至 succeeded/failed
- [ ] 能读取 OSS 中的 localized_text
- [ ] 能成功创建 step2 Job
- [ ] 能识别 signals.passed 和 optimization_prompt
- [ ] 能在 step2 失败时重跑 step1（注入建议到 work_note）
- [ ] 能成功创建 step3 Job
- [ ] 能读取 OSS 中的 translated_text

**Callback 对接**：
- [ ] 实现 `/internal/ai-callbacks/novel-localization` 接口
- [ ] 验证 callback 签名（HMAC-SHA256）
- [ ] 验证 callback timestamp（防重放）
- [ ] 实现去重（按 job_id + event）
- [ ] 返回 2xx 表示接收成功

**错误处理**：
- [ ] 处理 22 个业务错误码
- [ ] 区分临时失败（重试）和永久失败（提示用户）
- [ ] 关键错误记录和告警

**非功能需求**：
- [ ] 单位时间并发 Job 数 > 5（无堆积）
- [ ] Job 轮询不超过 5 分钟（使用指数退避）
- [ ] 日志可被集中日志系统采集
- [ ] 部署前已完成单元测试、集成测试、压力测试

## 3. 使用范围和限制

### 3.1 支持的输入

- ✅ UTF-8 文本，最大 1 MB（直接传）
- ✅ UTF-8 文本，最大 5 MB（通过 OSS 对象传）
- ❌ 二进制文件（图片、PDF、Word）
- ❌ HTML、Markdown（暂不支持结构解析）

### 3.2 支持的模型

- ✅ OpenAI gpt-4o-mini（默认）
- ✅ 其他 OpenAI 模型（由 AI 能力层配置决定）
- ⚠️ 其他厂商模型（后期可扩展）

### 3.3 支持的语言

- ✅ 中文小说本地化、校验、翻译为英文
- ⚠️ 其他语言（暂不支持）

### 3.4 并发限制

| 限制项 | 数值 | 说明 |
|---|---|---|
| 单个调用方的并发 Job 数 | 无限制 | 但建议不超过 100 |
| 单个 Job 的 Celery 任务数 | 根据分块而定 | P1: 1 个，P5: N+2 个 |
| 单次请求超时 | 30 秒 | API 调用的响应时间 |
| 任务执行超时 | 30 分钟 | Job 从 queued 到 succeeded 的最长时间 |

## 4. 费用和资源使用

### 4.1 API 调用费用

- 📊 **模型费用**：由 OpenAI 收费，与输入/输出 token 数相关
- 📊 **OSS 存储**：由阿里云收费，与大文本 artifact 存储时间相关
- ✅ **API 调用本身**：免费（AI 能力层不单独收费）

### 4.2 资源优化建议

**降低 token 消耗**：
- 使用简洁的 Prompt（不必过度详细）
- 对长文本进行分割（但分割过多会影响一致性）
- 考虑使用 gpt-4o-mini 而非 gpt-4o（费用低 5-10 倍）

**降低 OSS 存储成本**：
- 定期清理已完成的 artifact
- 如果结果存储在自己的业务库，可删除 OSS 中的备份

## 6. 故障排查

### 6.1 常见问题快速排查

| 问题 | 可能原因 | 排查步骤 |
|---|---|---|
| `CONNECTION_REFUSED` | AI 能力层不可达 | 检查地址、防火墙、DNS |
| `INVALID_API_KEY` | API 密钥错误或过期 | 确认 Authorization header 格式 |
| `INPUT_TOO_LARGE` | 输入超过限制 | 用 `len(text)` 检查，或改用 oss_object |
| `JOB_TIMEOUT` | Job 执行超过 30 分钟 | 检查输入大小，考虑分割后重试 |
| Callback 无法接收 | AI 能力层无法访问后端 | 检查后端 callback URL 是否可公网访问 |

### 6.2 日志查询

**AI 能力层日志**：
- 服务器：`/var/log/ai-novel-localization/`
- 关键字：job_id, job_type, status

**后端日志**：
- 记录所有 Job 创建、轮询、完成
- 记录 Callback 接收和签名验证结果
