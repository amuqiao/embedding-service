# 小说本地化方法论
## 【核心原则：不可见本地化】
- 目标：消除所有"文化指纹"（Cultural Fingerprints）
- 标准：故事逻辑、情感反应、社会规则必须符合美国主流文化认知
- 禁区：保留任何需要注释才能理解的文化概念
- 注意：无需本地化的内容，保留原文无需修改

## 【执行流程：三层转换法】
### 第一层：世界观重构（Setting Transplantation）
1. **地理锚定**：
   - 将故事迁移至具体的美国地理坐标（需选择符合原故事气候/城市气质的地点）
   - 替换所有中文地标为美国对应物，保持空间逻辑（如"高架桥堵车"→"Interstate 405堵车"）
   - 社会环境：替换所有中国特色的制度性场所（如民政局→City Hall/Courthouse；派出所→Local PD/Sheriff's Office）

2. **社会体系适配**：
   - 法律逻辑：婚姻、继承、合同、刑事责任等必须符合美国州法律（默认California/New York，除非有特定需求）
   - 阶层标识：用美国版的社会阶层符号替换
   - 行业文化：如涉及医疗场景应出现Insurance/Co-pay/Copay等概念，急诊室文化而非门诊文化
   - 阶层标识转换：用美国版的社会阶层符号替换，例如
      -学区房 → Good School District + 高Property Tax焦虑
      -公务员 → Federal Employee/Teacher/Union job（强调pension和job security）
      -"暴发户" → Nouveau riche（强调旧钱vs新钱文化）

注意：小说不是说明文，不要为了本地化而强行把简单的句子改复杂，增加小说阅读成本。如果原来的词不出戏，就可以不改

### 第二层：角色系统重建（Character Reconstruction）
1. **命名策略**（需符合人物阶层与年代）：
   - 主角：使用Top 100美国婴儿名，但避免过于"老外"的名字（如Wang→Ryan/Wyatt；Li→Chloe/Emma）
   - 配角：使用能暗示社会地位的名字（精英→Preston/Whitney；工薪→Danny/Jessica）
   - 姓氏：确保族裔中性（Miller/Smith/Johnson/Jones/Brown），除非特定族裔设定
   - 注意：小说中的人称代词，需要找到对应的角色，替换为角色名的恰当表达（如男主叫做高云旭，本地化后改为Elon Musk；如果小说中有高先生、小高、老高之类的描述，需要根据语境、场合、人物关系选择用Elon Musk、Musk、Elon来替换）

2. **关系网络美国化**：
   - 亲属称谓：须符合美式文化，例如
     - 公公/婆婆 → Father-in-law / Mother-in-law（直呼其名或Sir/Ma'am也常见）
     - 舅妈/姨妈 → Aunt [名字]（美国不区分父系母系）
     - 表哥/堂弟 → Cousin [名字]（美国无堂表之分）
     - 小名/昵称 → 美式昵称（如"小明"→"Mick", "小红"→"Red"或直接省略）
   - 社交称谓：须符合美式文化，例如
     - 主任/局长 → Manager / Chief / Commissioner / Supervisor（根据具体职能）
     - 老师（非教师职业）→ 不使用，转换为"Sir/Ma'am"或直呼其名
     - 师傅（司机/技工）→ Sir / Driver / 直呼其名
  - 人称代词重构：严格追踪角色名映射：例如若原文"高云旭"映射为"Ethan Miller"，则：
     - 高先生 → Mr. Miller / Sir / Miller（职场）
     - 小高 → Ethan（亲友）/ Miller（上司）
     - 老高 → Old man Miller（亲密调侃）/ Ethan Sr.（父子同场景）
     - 那小子 → That Miller kid / Ethan

### 第四层: 文风与叙事保护（Narrative Integrity）
此层为新增，确保不破坏文学性：
-句法节奏保留：
  原文若使用短促、断续的中文短句（表现焦虑），转换为英文简洁风格（Hemingway-esque），而非复杂从句
  原文若使用长卷轴式描写，保留流动性，避免切成碎片
-意象系统适配：
  "落叶归根" → "Coming home for Thanksgiving" 或 "Roots in the hometown"
  "雪中送炭" → "Showing up with a six-pack when you're down"（美国等价情感）
  避免机械替换：若"梅花"象征坚韧，转换为"Oak tree"而非强行解释梅花
-对话逻辑美国化：
  删除中式含蓄（"你吃了吗"开场），转换为美式直接（"We need to talk"）
  保留潜台词（subtext），但转换为美式语境（如用"football game small talk"掩饰尴尬）
  幽默转换：将语言梗（谐音、成语）转换为文化梗（Pop culture reference, Sports reference）

### 【质量控制清单】（自检用）
完成本地化后，必须确认以下零宽容条款：
[ ] 法律合规性：所有涉及婚姻、财产、犯罪的程序符合目标州现行法律
[ ] 货币统一：所有金额转换为USD，收入水平符合当地购买力（如"月薪一万人民币"→"月薪4k-5k USD"在Midwest，或"7k USD"在NYC/LA）
[ ] 无注释需求：没有任何情节需要读者了解中国文化才能理解
[ ] 称谓一致性：同一场景中，角色称谓符合美国社交距离（如不会突然从"Mr. Smith"跳转到"David"而无过渡）
[ ] 情感真实性：角色的决策动机符合美国个人主义价值观（如"为了父母牺牲"需转换为"个人选择"或"内疚驱动"）
[ ] 时代准确性：提及的科技、品牌、流行文化符合设定年代（如2020s不会用Facebook作为主要社交工具）
