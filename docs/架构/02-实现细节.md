## 二、核心执行流程

### 2.1 POST /jobs 请求流程

```python
# 1. API 层验证 (routes/jobs.py)
POST /jobs
├─ Pydantic 自动验证 (extra="forbid" 拒绝 execution_mode 等)
├─ require_service_auth 验证 Bearer Token
└─ 调用 create_job service

# 2. Service 层处理 (services/jobs.py)
create_job(payload, caller_id)
├─ _validate_create_request
│  ├─ 验证 job_type 有效性 (from prompt-templates)
│  ├─ 验证 model_id 可用 (from model_registry)
│  ├─ 验证 prompt.blocks 完整性 (key/role 对应)
│  └─ 验证 callback.url 是 HTTPS
├─ 检查幂等性 (client_request_id)
│  └─ 若 24h 内相同 caller_id + client_request_id，返回旧 job_id
├─ JobRepo.create (存储到 DB)
│  └─ status='queued', progress_percent=0
└─ 投入 Celery (process_job_task.delay(job_id))

# 3. 返回响应
HTTP 202 Accepted
{
  "job_id": "uuid",
  "status": "queued",
  "status_url": "/api/v1/novel-localization-ai/jobs/{job_id}",
  "created_at": "2026-06-10T12:00:00Z"
}
```

### 2.2 异步执行流程 (Celery)

```python
# tasks/jobs.py: process_job_task
async _process(job_id):
├─ 1. 加载 Job 和输入
│  ├─ JobRepo.get(job_id)
│  ├─ _load_input_text(job)
│  │  ├─ 从 OSS 读取 (storage.read_text)
│  │  ├─ 检查大小 (≤ 5MB)
│  │  ├─ 校验 hash (content_hash)
│  │  └─ 检查编码 (UTF-8)
│  └─ JobRepo.mark_running()
│
├─ 2. 执行 Job (executor.run_ai_job)
│  ├─ _prompt_messages(prompt_payload, input_text, job_type)
│  │  └─ 组装 messages (system="" + user + work_note)
│  ├─ generate_text(model_id, messages, timeout=300s)
│  │  └─ OpenAI API 调用
│  └─ _parse_{step1|step2|step3}_output(model_output)
│     └─ 按格式标记提取 artifacts + signals
│
├─ 3. 持久化结果
│  ├─ _persist_large_artifacts(job, result)
│  │  └─ 大文本写 OSS (localized_text/translated_text)
│  ├─ JobRepo.mark_succeeded(job_id, result_data)
│  │  └─ status='succeeded', progress_percent=100
│  └─ db.commit()
│
└─ 4. 发送 Callback
   ├─ 重新加载 Job (获取最新数据)
   ├─ deliver_callback(job)
   │  ├─ 生成 HMAC 签名 (X-AI-Service-Signature)
   │  ├─ 重试 3 次 (10s, 30s, 60s)
   │  └─ 返回 2xx 才算成功
   └─ 返回执行结果
```

## 三、数据模型

### 3.1 AIJob 表结构

```sql
CREATE TABLE ai_jobs (
  id UUID PRIMARY KEY,
  caller_id VARCHAR(64) NOT NULL,
  client_request_id VARCHAR(255),
  job_type VARCHAR(96) NOT NULL,
  model_id VARCHAR(128) NOT NULL,
  status VARCHAR(24) NOT NULL,  -- queued|running|succeeded|failed
  progress_percent INT DEFAULT 0,
  progress_text VARCHAR(255),
  input_payload JSONB,          -- {"oss": {...}}
  output_payload JSONB,         -- {"type": "oss_prefix", "oss_prefix": "..."}
  callback_payload JSONB,       -- {"url": "...", "events": [...]}
  prompt_payload JSONB,         -- {"blocks": [...]}
  result_payload JSONB,         -- {"artifacts": [...], "signals": {...}}
  error_payload JSONB,          -- {"code": "...", "message": "..."}
  celery_task_id VARCHAR(255),
  created_at TIMESTAMP NOT NULL,
  started_at TIMESTAMP,
  finished_at TIMESTAMP,
  updated_at TIMESTAMP NOT NULL,
  expires_at TIMESTAMP NOT NULL,  -- created_at + 24h
  INDEX(caller_id, client_request_id),
  INDEX(status),
  INDEX(expires_at)
);
```

### 3.2 Pydantic Schema

```python
# 请求
class CreateJobRequest(StrictBaseModel):
  client_request_id: str | None
  job_type: str
  model_id: str
  source: JobSource          # 只有 oss 字段（forbid 其他）
  callback: CallbackConfig
  prompt: PromptConfig       # blocks: [system, user, work_note]

# 响应
class JobStatusResponse(StrictBaseModel):
  job_id: UUID
  job_type: str
  status: str                 # queued|running|succeeded|failed
  progress_percent: int       # 0-100
  progress_text: str | None
  result: JobResult | None
  error: JobError | None
  created_at: datetime
  started_at: datetime | None
  finished_at: datetime | None

class JobResult(StrictBaseModel):
  artifacts: list[Artifact]
  signals: dict[str, Any]

class Artifact(StrictBaseModel):
  key: str
  type: str
  label: str
  storage: Literal["oss_object"] | None
  oss_key: str | None         # 大文本
  content: Any | None          # 短文本
  apply_mode: Literal["replace", "append"] | None
```

## 五、输出解析逻辑

### 5.1 Step1 (Localize) 解析

```python
def _parse_step1_output(text: str) -> tuple[str, str]:
  # 1. 提取标记之间的内容
  localized = _extract_between(
    text,
    "===本地化正文开始===",
    "===本地化正文结束==="
  )
  notes = _extract_between(text, "===工作注释开始===", "===工作注释结束===")
  
  # 2. 验证
  if not localized:
    raise "缺少本地化正文标记"
  if notes is None:
    raise "缺少工作注释标记"
  if _looks_like_english_translation(localized):
    raise "正文疑似英文译文，step1 必须输出中文"
  
  # 3. 返回
  return localized.strip(), notes.strip()
```

### 5.2 Step2 (Review) 解析

```python
def _parse_step2_output(text: str) -> tuple[bool, str, str]:
  # 1. 查找校验结论
  conclusion = re.search(r"【校验结论】\s*(通过|不通过)", text)
  if not conclusion:
    raise "缺少【校验结论】"
  
  passed = conclusion.group(1) == "通过"
  
  # 2. 若不通过，提取问题说明和建议
  if not passed:
    problem = _extract_between(text, "【问题说明】", "【建议工作注释】")
    suggestion = _extract_between(text, "【建议工作注释】", "$")
    if not problem or not suggestion:
      raise "不通过时必须提供问题说明和建议"
  else:
    problem = "已满足"
    suggestion = ""
  
  # 3. 返回
  return passed, problem, suggestion
```

### 5.3 Step3 (Translate) 解析

```python
def _parse_step3_output(text: str) -> str:
  translated = _extract_between(
    text,
    "===英文翻译开始===",
    "===英文翻译结束==="
  )
  
  if not translated:
    raise "缺少英文翻译标记"
  if _looks_like_chinese(translated):  # 反向检查
    raise "翻译内容疑似中文"
  
  return translated.strip()
```

## 六、Callback 机制

### 6.1 签名生成

```python
def _sign(timestamp: str, body: bytes) -> str:
  # 签名原文: timestamp + "." + body
  message = timestamp.encode() + b"." + body
  
  # HMAC-SHA256
  digest = hmac.new(
    settings.CALLBACK_SIGNING_SECRET.encode(),
    message,
    hashlib.sha256
  ).hexdigest()
  
  return f"sha256={digest}"
```

### 6.2 Callback 请求

```python
async def deliver_callback(job: AIJob):
  callback = job.callback_payload
  url = callback.get("url")
  event = "job.succeeded" if job.status == "succeeded" else "job.failed"
  
  # 检查事件订阅
  if event not in callback.get("events", ["job.succeeded", "job.failed"]):
    return
  
  # 组装 body
  body = json.dumps(build_callback_body(job), ensure_ascii=False)
  
  # 生成签名
  timestamp = datetime.now(timezone.utc).isoformat()
  headers = {
    "X-AI-Service-Job-Id": str(job.id),
    "X-AI-Service-Event": event,
    "X-AI-Service-Timestamp": timestamp,
    "X-AI-Service-Signature": _sign(timestamp, body.encode())
  }
  
  # 重试 3 次: 0s, 10s, 30s, 60s 延迟
  for delay in [0, 10, 30, 60]:
    if delay:
      await asyncio.sleep(delay)
    try:
      response = await client.post(url, content=body, headers=headers)
      if 200 <= response.status_code < 300:
        return  # 成功
    except:
      continue
  
  # 失败 3 次后放弃（但 Job 状态已保存）
```

## 七、错误处理

### 7.1 异常映射

```python
class AppError(Exception):
  def __init__(self, code: str, message: str, details: dict, status_code: int):
    self.code = code
    self.message = message
    self.details = details
    self.status_code = status_code

# 映射关系
错误场景 → status_code + error.code:
├─ Forbidden field → 422 INVALID_INPUT
├─ 无效 job_type → 422 INVALID_JOB_TYPE
├─ 模型不可用 → 422 MODEL_NOT_AVAILABLE
├─ 输入过大 → 422 INPUT_TOO_LARGE
├─ OSS 读取失败 → 422 OSS_FETCH_FAILED
├─ 模型调用失败 → 502 MODEL_CALL_FAILED
├─ 输出解析失败 → 502 MODEL_OUTPUT_INVALID
└─ 其他异常 → 500 Internal Server Error
```

### 7.2 异常处理流程

```python
# routes 层
@app.exception_handler(AppError)
def app_error_handler(request, exc):
  return JSONResponse(
    status_code=exc.status_code,
    content={"error": {"code": exc.code, "message": exc.message}}
  )

# Celery 层
@celery_app.task
def process_job_task(self, job_id):
  try:
    return asyncio.run(_process(job_id))
  except SoftTimeLimitExceeded:
    # 超时，标记 JOB_TIMEOUT
    await _mark_timeout(job_id)
  except Exception as exc:
    # 其他异常，标记 failed
    await _fail(job_id, exc)
    raise
```

## 十、性能考虑

### 10.1 瓶颈分析

```
网络 IO:
  ├─ OSS 读取: 取决于对象大小和网络质量
  ├─ LLM 调用: 取决于模型推理时间 (通常 30-60s)
  └─ Callback: 取决于用户侧应用响应

计算:
  ├─ JSON 解析: 快速（< 1ms）
  ├─ 提示词组装: 快速（< 10ms）
  └─ 输出解析: 快速（< 100ms 正则匹配）
```

### 10.2 优化建议

```
短期:
├─ 缓存 prompt-templates (已做)
├─ 缓存 model_registry (可做)
└─ 减少 DB 查询 (使用连接池)

中期:
├─ 模型批处理 (多个 job 共享一次调用)
├─ 结果缓存 (相同输入 + prompt 的缓存)
└─ 异步 OSS 读写 (减少阻塞)

长期:
├─ 模型蒸馏或量化 (降低延迟)
├─ 本地轻量级模型 (简单任务)
└─ 多地域部署 (地理位置优化)
```

## 总结：关键实现细节
